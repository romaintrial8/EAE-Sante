# Cocarde

Préparation au concours de l'École de l'air et de l'espace 2027 : plan d'entraînement, santé Garmin (via Intervals.icu), tests au barème et échéances.

- `npm install` · `npm test` · `npm run typecheck` · `npm run build`
- Publication automatique sur GitHub Pages à chaque envoi sur `main`.
- Documentation : `docs/PRD.md`, `docs/SPECS-TECH.md`, `docs/ETAT.md`.

Le dépôt est public : il contient le plan, les jalons et les résultats du test S0. Aucune donnée Garmin n'y est envoyée : elles restent sur l'appareil.
